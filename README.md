# 🐉 Dragon Ball Z — Legacy Trilogy

### Three GBA adventures. One application. Two screens.

**Legacy Trilogy** is an unofficial fan project that brings three Dragon Ball Z Game Boy Advance adventures together in one Android application, specially adapted for the **AYN Thor Max** dual-screen handheld.

| The Legacy of Goku | Europea | 🇬🇧 🇪🇸 🇫🇷 🇩🇪 🇮🇹 | ✅ Disponible |

### ✨ Características

- Tres juegos integrados en una sola APK.
- Adaptación específica para las dos pantallas de AYN Thor Max.
- Pantalla superior panorámica y adaptativa.
- Pantallas inferiores personalizadas para los tres juegos.
- Menús táctiles, estado, habilidades, inventario y mapas según el juego.
- Launcher personalizado con música para cada aventura.
- Primera pulsación para seleccionar; segunda para iniciar.
- Importación de las ROM y BIOS por el usuario.
- Aviso automático **«Agregar BIOS GBA»** cuando falta la BIOS.
- Recursos gráficos preparados a partir de la ROM compatible.
- Soporte multidioma mediante las ROM europeas de Legacy I y Legacy II.
- Compatible con Buu's Fury en inglés y con la modificación española admitida.

### 🏆 RetroAchievements

**The Legacy of Goku I** ya dispone de integración con RetroAchievements.

Seguimos trabajando en:

- Compatibilidad de RetroAchievements para **The Legacy of Goku II**.
- Compatibilidad de RetroAchievements para **Buu's Fury**.
- Integración del **modo Hardcore**.

Estas funciones todavía no se anuncian como disponibles para los tres juegos.

### 📲 Instalación y uso

1. Instala la APK de Legacy Trilogy en una AYN Thor Max compatible.
2. Abre la aplicación.
3. Si aparece **«Agregar BIOS GBA»**, selecciona tu archivo BIOS de Game Boy Advance.
4. Pulsa sobre uno de los tres juegos e importa una ROM compatible.
5. Espera a que se preparen sus recursos.
6. Escucha la música del juego seleccionado.
7. Pulsa nuevamente sobre el mismo juego para iniciarlo.

La BIOS y las ROM deben ser aportadas por el usuario. Este proyecto no proporciona enlaces para descargarlas.

### 💾 Partidas

Los tres juegos mantienen sus respectivos datos de guardado. Las dos variantes admitidas de Buu's Fury utilizan una única ubicación de partida, sin separarla por idioma.

## 🇬🇧 English

### Supported games

| Game | Supported ROM | Languages | RetroAchievements |
|---|---|---|---|
| The Legacy of Goku | European | English, Spanish, French, German, Italian | ✅ Available |
| The Legacy of Goku II | European | English, Spanish, French, German, Italian | 🚧 In progress |
| Buu's Fury | USA GoodTools / supported Spanish modification | English, Spanish | 🚧 In progress |

**Buu's Fury has no European multilingual ROM.** The project supports the verified English USA GoodTools ROM and the compatible Spanish-modified ROM.

### Features

- Three games in one Android APK.
- Optimized for AYN Thor Max dual screens.
- Widescreen gameplay on the upper screen.
- Custom interfaces and touch controls on the lower screen.
- Custom launcher with individual game music.
- First tap selects a game; second tap launches it.
- User-provided GBA BIOS and compatible ROMs.
- Automatic BIOS import prompt on first launch when needed.
- Multilingual support through the European Legacy I and II ROMs.

### RetroAchievements roadmap

RetroAchievements integration is available for **The Legacy of Goku I**.

Support for **The Legacy of Goku II**, **Buu's Fury**, and **Hardcore Mode** is under development. These features are not yet available across the full trilogy.

### Installation

1. Install the Legacy Trilogy APK on a compatible AYN Thor Max.
2. Launch the application.
3. Import your own GBA BIOS when prompted.
4. Choose a game and import its compatible ROM.
5. Wait for resource preparation.
6. Tap the selected game again to start playing.

BIOS and ROM files must be supplied by the user. No ROM or BIOS download links are provided.
